## Description measurements

Only explicit clear-opening and frame measurements were transcribed. Cover stamps and nominal product names are not assumed to be physical cover dimensions. Unverified fields show “Not specified” and can be completed in Admin.

The 54-inch annotated photo states 1115 mm clear opening, while the other view states 1155 mm. That measurement is left blank. The 40-ton data sheet lists a 595 mm frame for a 450 mm opening, while the photographs label a 600 mm frame. Photo-specific values were retained; the sheet was not applied across unmatched variants.

Some filenames omit units. Units were filled only when explicit in the photo, filename or another named view; those cross-view matches are noted in frp-import-review.json.

## Admin and publishing

Add or edit a product to select an existing capacity/size or type a new one. Saved active products supply the public dropdown options. Description contains separate Clear opening, Frame size and Cover size inputs.

Local edits remain drafts until exported and published. Online admin saves use the existing authenticated API. A previously populated online store takes priority over the bundled initial catalogue; deploying code alone does not replace stored live inventory. This task has not deployed or overwritten live data.
